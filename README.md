# ☠️ Secret Graveyard

A cybersecurity research project focused on GitHub search,
exposed-secret prevention, and responsible disclosure.

## Objectives

- Learn GitHub search syntax and dorks.
- Understand how API keys become exposed.
- Practise secret detection using TruffleHog.
- Document security findings safely.
- Learn responsible vulnerability disclosure.

## Security Tools

- TruffleHog
- GitHub Secret Scanning

## Safety Rules

- Never use another person's exposed credentials.
- Never publish real API keys or passwords.
- Use synthetic credentials for testing.
- Report genuine exposures responsibly.
